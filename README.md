# KUSSO

KUSSO is a PHP and MySQL café management system with an admin dashboard, point-of-sale workflow, kitchen order management, inventory tracking, sales reports, expense management, and PayMongo payment support.

## Features

- Role-based authentication for admins, cashiers, and baristas
- Product and category management
- Product flavors, ingredients, and ingredient-category assignments
- Inventory and low-stock monitoring
- Point of sale order creation and payment processing
- Kitchen order queue and order completion workflow
- Sales reports, archived sales, and expense management
- User management and deleted-user recovery
- Database backup and recovery tools
- Optional PayMongo payment integration

## Requirements

- Windows with [Laragon](https://laragon.org/) or another PHP web server
- PHP with PDO and PDO MySQL enabled
- MySQL or MariaDB
- A modern web browser
- PayMongo credentials if online payments are enabled

## Installation

1. Place the project in the web root. For Laragon, use:

   ```text
   C:\laragon\www\kusso
   ```

2. Start Apache and MySQL from Laragon.

3. Create a MySQL database named `kusso`.

4. Import the project's database schema and seed data into the `kusso` database. This repository does not currently include a SQL dump, so the required tables must be created from the database source used by your deployment.

5. Review the database connection in `includes/config.php`:

   ```php
   $host = "localhost";
   $db_name = "kusso";
   $username = "root";
   $password = "";
   ```

   Change these values to match your local database credentials.

6. Open the application at:

   ```text
   http://localhost/kusso/login.php
   ```

## User Roles

- **Admin**: dashboard, products, categories, inventory, users, reports, expenses, archives, and backups
- **Cashier**: point of sale and order/payment operations
- **Barista**: kitchen order queue and order status updates

Users must exist in the `users` table with a password stored using PHP's `password_hash()` format. The role value is used to route users after login.

## Payment Configuration

PayMongo-related settings are kept in `includes/paymongo_config.php`. Configure the required credentials and webhook settings before enabling online payments. Do not commit secret keys to source control.

## Main Entry Points

- `login.php` - authentication and role-based routing
- `index.php` - admin dashboard
- `pos/index.php` - cashier point of sale
- `kitchen.php` - kitchen order management
- `manage_products.php` - product administration
- `manage_inventory.php` - inventory management
- `sales_report.php` - sales reporting

## Project Structure

```text
includes/   Shared configuration, authentication, layout, and payment helpers
pos/        Point-of-sale pages and order operations
assets/     Images and frontend demo assets
css/        Stylesheets
js/         JavaScript files
backups/    Database backup files generated by the application
logs/       Application logs
```

## Development Notes

- The application uses PHP sessions for authentication.
- Database access is handled with PDO.
- The default timezone used by the dashboard is `Asia/Manila`.
- Keep generated backups and logs protected from public access in production.
- Use HTTPS and non-default database credentials when deploying outside a local development environment.
